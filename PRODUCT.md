# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- Primary: Malaysian Form 3 (KSSM) students studying circle theorems, and their teachers.
- Goal: Students need to download the PinMetry APK for offline use or open the web app. Teachers need to evaluate or use it for classroom instruction.

## Product Purpose

PinMetry is a geometry & protractor tool for Angles and Tangents of Circles (Form 3 KSSM Mathematics). The landing page exists to distribute the Android APK and direct users to the web app.

## Positioning

An interactive geometry learning tool purpose-built for the Malaysian KSSM Form 3 Mathematics curriculum — specifically circle theorems. Not a general calculator, not a game.

## Operating Context

- Users arrive from school recommendations, Google Play alternative searches, or teacher links.
- Mobile-first — most visitors are on Android phones.
- The web app runs at https://xtra15.github.io/PinMetry/
- APK is hosted on MediaFire (direct download) and GoFile (mirror).

## Capabilities and Constraints

- Landing page is a single static HTML file with inline CSS and JS. No build step.
- APK is Android-only. iOS is not supported — this must be clearly communicated.
- Logo image: `pinmetry-logo.webp`
- Links to: Documentation (GitHub Pages), Source (GitHub), Web App, APK mirrors.

## Brand Commitments

- Name: PinMetry
- Version: v13.3 (shown in footer)
- iOS not supported — warning is required content

## Evidence on Hand

- Existing live page at https://xtra15.github.io/websiteTest/
- Logo asset: `pinmetry-logo.webp`

## Product Principles

1. The download CTA must be immediately visible above the fold.
2. iOS users must be clearly warned before they attempt to download.
3. Mobile-first: the page must look and feel native on a phone screen.

## Accessibility & Inclusion

- Support device text sizing.
- Touch targets minimum 44px.
